# Vibe Weather Portal

Portal Meteorológico de Alto Rendimiento usando Open Meteo API.

## Arquitectura

- Frontend: Vanilla JS, HTML5, CSS3.
- Backend: Node.js con Express.
- Patrón: Clean Architecture.

## Requisitos Previos

- Node.js versión 14 o superior
- npm (viene incluido con Node.js)

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/pabsanchi/VIBEWEATHER.git
   cd VIBEWEATHER
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

## Ejecución Local

Para ejecutar el proyecto localmente:

1. Inicia el servidor en modo producción:
   ```bash
   npm start
   ```

2. O para desarrollo (con recarga automática):
   ```bash
   npm run dev
   ```

3. Abre tu navegador y ve a `http://localhost:3000`

El servidor se ejecutará en el puerto 3000 por defecto. Si necesitas cambiar el puerto, puedes usar una variable de entorno:
```bash
PORT=4000 npm start
```

## Tests

Para ejecutar los tests:

```bash
npm test
```

Para ejecutar los tests en modo watch (se ejecutan automáticamente al cambiar archivos):
```bash
npm run test:watch
```
